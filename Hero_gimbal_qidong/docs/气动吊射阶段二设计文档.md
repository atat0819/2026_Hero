## 1. 系统气路与执行器角色

```
气源 → [电磁阀1 PI0] → [比例阀 GP8403] → 快开阀P ──A── [气室] (压力储能罐)
              ↑                              │
          击发开关 = 关闭它                  E
                                   [出弹口] (唯一出口, 推弹处)
```

| 执行器 | 平时(待发) | 击发瞬间 | 击发后 |
|---|---|---|---|
| 电磁阀1 (PI0) | **开**（保持通路, 气室一直充压） | **关**（切断气源） | 重新开（恢复充压） |
| 比例阀 (GP8403) | 保持目标开度（DAC 锁存, 气室压力=设定气压） | 输出 0V（帮助 P 侧泄压） | 回目标开度 |
| 推杆 (PH12) | 无弹缩回 / 有弹顶死 | 顶死（弹丸在出弹口） | 缩回（下一颗弹进入） |

**核心机制**: 快开阀（快排阀）慢充快放——充压时 P→A 通气室（比例阀压力直通），
击发时供气侧泄压 → 阀芯被气室压力压换向 → 气室气体 A→E 瞬间冲入出弹口推弹。
**击发动作 = 电磁阀1关 + 比例阀0V**（快开阀机械自动换向）。

**操作模型: 自动上膛 + 手动击发** —— 推杆顶死由红外自动完成（上膛），
击发时机由**操作手拨 s2 拨杆**决定（扣扳机），可把握瞄准时机。

## 2. 架构决策: 为什么只用一个状态机

**一个发射时序状态机, 不分比例阀/电磁阀各自的状态机。**

判断标准: **执行器是否属于同一个串行流程。**
吊射的推杆、电磁阀1、比例阀**不能独立并行**——推杆不到位就不能击发、
击发完才能缩杆、缩杆后气室才能恢复充压, 顺序死死绑定 = 一条串行流水线。

| 角色 | 在状态机里的位置 |
|---|---|
| 电磁阀2 (推杆) | **动作输出** — PRIME 进入即伸出, BACK 进入即缩回 |
| 电磁阀1 (充压/击发) | **动作输出** — FIRE 进入即关闭, 其他状态打开 |
| 比例阀 (GP8403) | **参数设定** — IDLE/BACK 写目标开度, FIRE 写 0V; DAC 锁存, 非状态机成员 |

**为什么不能拆成三个**: 三个状态机需要互相等待同步（推杆顶死→电磁阀1才能关→
比例阀才能降）, 等于把一条流水线切成三份再重新同步, 逻辑散落 + 引入"推杆未
到位就击发"之类的时序 bug 风险。

**什么时候才该拆**: 两个流程完全独立并行（如云台 yaw/pitch 各自控制）。
反例验证: 拨弹轮 feeder_fsm 同样单状态机管单发/连发/反转/冷却——拨弹流程
也是串行的, 吊射一模一样。

## 3. 完整发射时序（单发）

```
T0  [IDLE]   气室满压待发: 电磁阀1开 + 比例阀保持开度 + 推杆缩回
T1  [PRIME]  红外检测到弹 → 推杆伸出顶死（密封进弹口, 弹丸在出弹口）
T2  [FIRE]   推杆到位(驻留计时到) + 操作手拨 s2 → 执行击发:
             电磁阀1关 + 比例阀0V → 快开阀换向 → 高压气体推弹出膛
T3  [BACK]   推杆缩回 + 电磁阀1重开 + 比例阀回目标开度（气室重新充压）
T4  → 回 [IDLE] 等待下一颗
```

- 弹丸出膛后红外光路恢复（变低）→ 下一颗弹进入 → 红外再触发上膛 → 循环
- 若击发失败弹丸未出膛（红外持续高）→ 回 IDLE 后自动再次上膛（PRIME），等下一次拨杆

## 4. 状态机设计（扩展现有 lob_shot_fsm）

### 4.1 输入结构体（新增 s2 拨杆）

```cpp
struct Struct_Lob_Shot_Input
{
    uint8_t s1;           // 遥控器 S1 挡位 (模式)
    bool    ir_has_ball;  // 红外防抖后: 进弹口有弹
    float   left_x;       // 左摇杆 X (手动挡推杆)
    uint8_t s2;           // 阶段二: 击发拨杆 (边缘触发, 拨一下打一发)
};
```

### 4.2 状态枚举（新增 FIRE / BACK）

```cpp
enum Enum_Lob_Shot_Status
{
    LOB_STATE_IDLE = 0,   // 待发: 气室满压, 推杆缩, 等红外
    LOB_STATE_PRIME,      // 上膛密封: 推杆顶死, 驻留计时等推杆到位, 等 s2 拨杆
    LOB_STATE_FIRE,       // 击发: 电磁阀1关 + 比例阀0V, 驻留计时等放气完成
    LOB_STATE_BACK,       // 复位: 推杆缩回 + 恢复充压, 驻留计时等气室回压
    LOB_STATUS_COUNT      // 状态总数 (4)
};
```

### 4.3 状态行为表（进入动作 / 驻留条件 / 退出条件）

| 状态 | 进入时执行 | 驻留 | 退出条件 |
|---|---|---|---|
| IDLE | 电磁阀1开 + 比例阀写目标开度 + 推杆缩 | 等红外 | 红外有弹 → PRIME |
| PRIME | 推杆伸出顶死 | 计时 `PRIME_HOLD_TICKS` + **等 s2 拨杆** | 到位计时到 **且** s2 拨杆触发 → FIRE |
| FIRE | **电磁阀1关 + 比例阀0V**（快开阀放气） | 计时 `FIRE_HOLD_TICKS` | 计时到 → BACK |
| BACK | 推杆缩回 + 电磁阀1开 + 比例阀回目标开度 | 计时 `BACK_HOLD_TICKS` | 计时到 → IDLE |

### 4.4 击发拨杆触发语义（s2, 边缘触发）

- **拨一下打一发**: FSM 内部记录上一轮 s2, 检测到 s2 **进入击发位**（边缘）才触发
- 击发位建议 = `Remote::UP`（常量 `FIRE_TRIGGER_POSITION` 可配置）
- 边缘触发防止"拨杆停留在击发位导致连打"
- 与拨弹轮的单发操作习惯一致（滚轮 tick = 边缘脉冲）

### 4.5 模式行为（s1 挡位, 停止优先不变）

| s1 | 模式 | 行为 |
|---|---|---|
| 0 / 2 | OFF | **全断**: 推杆缩 + 电磁阀1关 + 比例阀0V（安全, 断气源） |
| 1 | AUTO | 自动上膛（红外） + s2 拨杆手动击发: IDLE→PRIME→FIRE→BACK→IDLE |
| 3 | MANUAL | 阶段一手动推杆（摇杆）; 手动模式同样可用 s2 拨杆击发（调试充压/放气用） |

### 4.6 输出接口（FSM 只算逻辑, 任务层执行）

```cpp
// 阶段二输出 (替代单一 Is_Pusher_Extended)
struct Struct_Lob_Shot_Output
{
    bool     pusher_extended;   // 推杆是否顶死 → solenoid_valve_2
    bool     charge_valve_open; // 电磁阀1 是否通(充压) → solenoid_valve_1
    uint16_t valve_opening_mV;  // 比例阀目标电压 → gp8403.Set_Voltage_mV()
};
```

任务层每 5ms: `fsm.Update(input)` → 取 output → 执行三个执行器。
GP8403 只在**开度变化时**才写（DAC 锁存, 避免每周期刷 I2C; 对比上次输出值即可）。

## 5. 可调参数清单（集中在 lob_shot_fsm.hpp, 1 tick = 5ms）

| 参数 | 含义 | 初值建议 | 标定方法 |
|---|---|---|---|
| `TARGET_OPENING` | 目标开度 %（打弹气压） | 80% | 手动模式调开度试弹道, 记录落点/气压表 |
| `FIRE_TRIGGER_POSITION` | 击发拨杆位置（s2 枚举值） | `Remote::UP` | 按操作手习惯 |
| `PRIME_HOLD_TICKS` | 推杆伸出到位等待 | 60 (300ms) | 手动模式观察推杆顶死所需时间 |
| `FIRE_HOLD_TICKS` | 放气保持时间 | 20 (100ms) | 弹丸出膛即可; 太长浪费气, 太短可能气压未泄完 |
| `BACK_HOLD_TICKS` | 充压恢复等待 | 100 (500ms) | 气压表观察气室回压时间（决定射速上限） |
| `MANUAL_DEADZONE` | 摇杆死区（阶段一已有） | 0.5 | 不变 |

## 8. 安全注意事项

- **上电安全（已有）**: 所有执行器初始关、比例阀 0V
- **OFF 挡 = 断气源**: 电磁阀1 关 + 比例阀 0V, 任何非激活挡位强制进入
- **推杆未顶死禁止击发**: 时序上 PRIME 驻留计时保证推杆先到位再允许拨杆击发
- 气源压力上限靠机械泄压阀, 比例阀开度标定从低往高试
- 首测气源用小压力, 确认气路无泄漏再升压
