# 云台全补偿前馈参数辨识流程

本文档记录 yaw 轴 `GimbalFullCompensation` 的 3 个核心参数辨识方法，方便下次重新辨识或换机械结构后复现。

对应代码：

```cpp
Alg::Feedforward::GimbalFullCompensation yaw_speed_dynamics_ff(
    kJ, dt, viscousfriction, coulombfriction, friction_deadzone);
```

参数含义：

```text
kJ                 惯量前馈系数
viscousfriction    粘滞摩擦系数
coulombfriction    库伦摩擦补偿
friction_deadzone  期望速度线性死区，不属于 3 个主辨识参数，但会影响零速抖动
```

当前 yaw 轴可用参数：

```cpp
Alg::Feedforward::GimbalFullCompensation yaw_speed_dynamics_ff(
    0.05f, 0.001f, 0.04f, 100.0f, 20.0f);
```

## 一、准备工作

辨识前先确认：

```text
1. yaw 速度反馈单位是 deg/s。
2. 1 rpm = 6 deg/s。
3. 30 rpm = 180 deg/s，60 rpm = 360 deg/s。
4. 底盘跟随、小陀螺先关闭，只辨识 yaw 轴本体。
5. 先辨识摩擦，再辨识 kJ。
```

做摩擦辨识时，先关掉 yaw 前馈：

```cpp
Alg::Feedforward::GimbalFullCompensation yaw_speed_dynamics_ff(
    0.0f, 0.001f, 0.0f, 0.0f, 20.0f);
```

确保 VOFA 至少发送：

```text
ch1 yaw_target_speed
ch2 yaw_current_speed
ch3 yaw_target_speed - yaw_current_speed
ch4 yaw_speed_pid_output
ch5 yaw_speed_ff_output
ch6 yaw_control_output
ch9 mg4005_state[1].velocity_rpm
ch10 mg4005_state[1].current_a
```

摩擦前馈关闭时，稳态下 `ch4 yaw_speed_pid_output` 或 `ch6 yaw_control_output` 可以近似看成维持匀速所需摩擦输出。

## 二、辨识粘滞摩擦和库伦摩擦

摩擦模型：

```text
u = Kv * w + Uc * sign(w)
```

其中：

```text
Kv = viscousfriction
Uc = coulombfriction
w  = yaw_current_speed，单位 deg/s
u  = 稳态速度 PID 输出，单位为 LK4005 扭矩命令
```

建议速度点：

```text
+30 rpm  -> +180 deg/s
-30 rpm  -> -180 deg/s
+60 rpm  -> +360 deg/s
-60 rpm  -> -360 deg/s
```

采数方式：

```text
1. 临时强制 yaw_target_speed 为固定速度。
2. 每个速度保持 1~2 秒。
3. 丢掉起步过渡，只取稳定段平均值。
4. 记录实际速度 yaw_current_speed 和 PID 输出 yaw_speed_pid_output。
```

正反向成对计算：

```text
同一速度幅值 w：

u_pos = +w 稳态 PID 输出
u_neg = -w 稳态 PID 输出

u_avg = (u_pos - u_neg) / 2
```

然后用：

```text
u_avg = Kv * w + Uc
```

对不同速度点做直线拟合：

```text
Kv = 直线斜率
Uc = 直线截距
```

简化手算示例：

```text
w1 = 180 deg/s, u_avg1 = 107
w2 = 360 deg/s, u_avg2 = 114

Kv = (114 - 107) / (360 - 180) = 0.039
Uc = 107 - 0.039 * 180 = 100
```

填入：

```cpp
Alg::Feedforward::GimbalFullCompensation yaw_speed_dynamics_ff(
    0.0f, 0.001f, 0.04f, 100.0f, 20.0f);
```

验证标准：

```text
1. 重新跑 ±30 rpm、±60 rpm。
2. ch4 yaw_speed_pid_output 稳态均值接近 0。
3. ch3 速度误差均值接近 0。
4. 松杆后不来回抖。
5. 如果松杆后抖，优先加大 friction_deadzone 或降低速度环 Ki。
```

故障判断：

```text
coulombfriction 太小：低速爬不动、卡顿、PID 输出长期偏大。
coulombfriction 太大：过零冲、松杆后回摆、低速来回震。
viscousfriction 太小：速度越高 PID 输出越大。
viscousfriction 太大：高速刹不住、速度有超前趋势。
```

## 三、辨识惯量前馈 kJ

惯量辨识必须建立在摩擦补偿已经可用的基础上。

先填入已辨识摩擦，`kJ` 从 0 开始：

```cpp
Alg::Feedforward::GimbalFullCompensation yaw_speed_dynamics_ff(
    0.0f, 0.001f, 0.04f, 100.0f, 50.0f);
```

临时给 yaw 速度模式正弦目标速度：

```cpp
float GetYawInertiaTuneSpeed(float t)
{
    return 50.0f * sinf(3.0f * PI * t)
         + 100.0f * sinf(PI * t);
}
```

其中：

```text
t 单位：秒
返回值单位：deg/s
```

接入位置：

```cpp
yaw_target_speed = GetYawInertiaTuneSpeed(yaw_inertia_tune_time);
yaw_inertia_tune_time += 0.001f;
```

建议用临时开关或 `BEGIN TEMP / END TEMP` 标记，辨识完成后彻底删除，避免影响正常速度模式。

VOFA 建议通道：

```text
ch1 yaw_target_speed
ch2 yaw_current_speed
ch3 yaw_target_speed - yaw_current_speed
ch4 yaw_speed_pid_output
ch5 yaw_speed_ff_output
ch6 yaw_speed_dynamics_ff.getFriction()
ch7 yaw_speed_dynamics_ff.getAccFeedforward()
ch8 yaw_control_output
ch9 yaw_inertia_tune_time
ch10 yaw motor current
```

整定步骤：

```text
1. kJ = 0，采一份基准数据。
2. 逐步增加 kJ，例如 0.03、0.05、0.06、0.08。
3. 每个参数采 10~20 秒数据。
4. 观察 ch1 目标速度和 ch2 实际速度的相位关系。
5. 同时观察 ch4 PID 输出 RMS 是否下降。
```

判断标准：

```text
ch2 滞后 ch1：kJ 偏小。
ch2 超前 ch1：kJ 偏大。
加减速瞬间过冲明显：kJ 偏大。
ch4 PID 输出 RMS 明显下降：kJ 有效。
ch4 高频抖动变大：kJ 偏大，或加速度微分噪声过大。
```

本次 yaw 轴数据结论：

```text
kJ = 0:
速度误差 RMS 约 7.66 deg/s
PID 输出 RMS 约 51.06

kJ = 0.05:
速度误差 RMS 约 7.88 deg/s
PID 输出 RMS 约 40.63

kJ = 0.08:
速度误差 RMS 约 8.86 deg/s
PID 输出 RMS 约 43.66
```

因此当前 yaw 轴建议：

```cpp
Alg::Feedforward::GimbalFullCompensation yaw_speed_dynamics_ff(
    0.05f, 0.001f, 0.04f, 100.0f, 20.0f);
```

## 四、视觉模式使用建议

速度模式辨识出的摩擦参数可以作为视觉模式初值，但视觉模式不能直接满额激进使用。

推荐视觉模式先保守：

```cpp
ALG::PID::PID yaw_version_angle_pid(
    10.0f, 0.0f, 0.0f, 2000.0f, 1000.0f, 100.0f);

ALG::PID::PID yaw_version_speed_pid(
    2.8f, 0.0f, 0.0f, 5000.0f, 1000.0f, 100.0f);

Alg::Feedforward::GimbalFullCompensation yaw_vision_dynamics_ff(
    0.0f, 0.001f, 0.02f, 50.0f, 50.0f);
```

视觉模式优先保证不抖：

```text
1. kJ 先保持 0。
2. 摩擦前馈先用速度模式的 50% 左右。
3. 视觉外环 Kp 比普通角度模式低。
4. 视觉目标需要滤波和限速。
5. 如果小陀螺下开前馈就抖，优先关闭视觉摩擦前馈，再确认底盘耦合问题。
```

## 五、辨识完成后的清理

辨识完成后必须删除或关闭：

```text
1. 固定速度强制给定。
2. 正弦速度辨识临时代码。
3. VOFA 中临时的 tune time 通道。
```

保留：

```text
1. GimbalFullCompensation 的参数。
2. 线性死区功能。
3. VOFA 中 PID 输出、前馈输出、总输出的分通道显示。
```
